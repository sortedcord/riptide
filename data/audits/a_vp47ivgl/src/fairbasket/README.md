# FairBasket web

Online grocery and household marketplace (Next.js pages router). Sellers list packaged goods; FairBasket runs search, cart, checkout and payments, and offers the FairPass membership (free delivery, monthly, UPI AutoPay or card mandate).

- `src/pages` routes, `src/components` UI, `src/lib` pricing/cart/consent logic, `src/data` seeded catalogue, `src/config` fees and company details.
